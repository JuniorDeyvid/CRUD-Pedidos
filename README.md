# CRUD de Pedidos

Projeto desenvolvido em Java para praticar
operações CRUD e orientação a objetos.

## Tecnologias
- Java
- IntelliJ IDEA
- Git e GitHub

## Funcionalidades
- Cadastro de pedidos
- Listagem de pedidos
- Atualização de pedidos
- Remoção de pedidos

## Objetivo
Praticar lógica de programação, orientação
a objetos e versionamento de código.
